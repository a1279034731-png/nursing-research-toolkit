# Contributing

Contributions are welcome if they improve reproducible nursing or clinical research workflows.

## Suitable contributions

- Bug fixes
- Documentation improvements
- Additional examples using synthetic data
- New utilities for scale scoring, Delphi studies, or evidence synthesis

## Privacy and data rules

Do not submit patient-identifiable data, hospital internal documents, ethics materials, access tokens, passwords, or private research datasets. Use synthetic or fully de-identified demonstration data only.

## Development workflow

1. Open an issue describing the problem or proposed change.
2. Create a branch for your work.
3. Add or update tests when possible.
4. Open a pull request with a clear summary.
